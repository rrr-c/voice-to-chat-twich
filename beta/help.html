⚙️ 初期設定
🔑 Twitch Client ID の取得

  1. Twitch Developer Console にアクセス

    dev.twitch.tv/console をブラウザで開く

  2. 「アプリケーションを登録」をクリック

    右上の「+ アプリケーションを登録」ボタン

  3. 必要事項を入力する

    名前は自由。カテゴリは「Chat Bot」など

  4. OAuth リダイレクト URI を設定

    アプリのセットアップ画面に表示されている URI をそのまま貼り付ける

  5. 登録後、「クライアントID」をコピー

    アプリのセットアップ画面に貼り付けて「保存して進む」をクリック

ℹ️Client ID はあなた自身のアプリ識別子です。他人に教えないよう注意してください。
🔐 Twitchログイン・連携

  1. 「Twitchでログイン」をクリック

    Twitch の認証ページに移動します

  2. 権限を確認して「許可」をクリック

    チャットへの書き込み権限 (user:write:chat) を要求します

  3. アプリ画面に戻り、ユーザー名が表示されれば完了

    以降はブラウザを閉じるまでログイン状態が続きます

⚠️アクセストークンはブラウザのメモリ内にのみ保持され、サーバーには送信されません。
🎙️ 基本的な使い方
🔘 マイクモードの選択
🔄 トグルモード

ボタンを一度押してON、もう一度押してOFF。両手が使えるため配信中のゲーム操作向け。

👆 PTTモード

ボタンを押している間だけ録音。誤認識を防ぎたいときや、短い発言に向いている。

📤 チャットを送信するには
🎙️
マイクをONにして話す
↓
👁️
「認識中...」エリアにリアルタイムで文字が表示される
↓
📝
発話が終わると「送信バッファ」に追加される
↓
🗣️
送信コマンド（初期値: チャット送信）と発話する
↓
✅
バッファの内容がTwitchチャットに送信される
🗣️ 音声コマンド一覧
  • 送信コマンド（初期値: チャット送信）
    バッファの内容をチャットに送信します。コマンドワード自体はメッセージから除去されます。
  • キャンセルコマンド（初期値: キャンセル）
    バッファの内容をすべて削除します。送信をやり直したいときに使います。
💡コマンドは「詳細設定」から自分の話し言葉に合わせて変更できます。
🧹 送信バッファのクリア

送信バッファ右上の クリア ボタンを押すと、バッファを即座に空にできます。音声コマンド「キャンセル」と同じ動作です。

🔧 詳細設定
🔄 自動再起動

「認識が切れたら自動で再開する」にチェックを入れると、音声認識が自然に終了した際に自動で再開します。
※ トグルモードのみ有効です。PTTモードでは機能しません。

💡長時間配信で毎回ボタンを押し直したくない場合に便利です。
⌨️ 音声コマンドのカスタマイズ
  • 送信コマンド — 発話してチャットを送信するキーワード
  • キャンセルコマンド — バッファを空にするキーワード

認識されやすい、はっきりした言葉に設定すると誤作動が減ります。例：送信、おくる

📺 送信先チャンネルの変更

「送信先」欄を空欄にすると自分のチャンネルに送信されます。
別のユーザー名（例: streamer123）を入力すると、そのチャンネルのチャットに書き込みます。

📖 エモート辞書の使い方

音声で認識された語句を、Twitchエモートコードなど任意の文字列に自動変換します。

🎤 カッパ → 💬 Kappa
🎤 ハイパー → 💬 HyperCool

追加方法

  1. 「認識語」に音声で読み上げる言葉を入力

    例: カッパ

  2. 「変換コード」に置き換えたい文字列を入力

    例: Kappa

  3. 「追加」ボタンをクリック

    テーブルに追加されると同時にローカルに保存されます

Import / Export

  • ⬆ Export  辞書を JSON ファイルとして保存します。バックアップや別端末への移行に利用できます。
  • ⬇ Import  JSON ファイルから辞書を読み込みます。既存の辞書に追加（マージ）されます。重複する「認識語」はスキップされます。
📄Import ファイルの形式: [{"word":"カッパ","code":"Kappa"}, ...]
🐛 デバッグログ

「デバッグログを表示する」をオンにすると、音声認識の内部イベントや通信ログが画面下部に表示されます。
問題を報告する際は 📋 ログをコピー で内容を取得できます。

🆘 トラブルシューティング
🎙️ マイク・音声認識
Q マイクボタンを押しても反応しない / 許可が求められない
A
  • ブラウザのマイク権限を確認してください。アドレスバー左の 🔒 アイコン → サイトの設定 → マイク を「許可」に変更します。
  • Chrome / Edge での動作を推奨します。Firefox や Safari は Web Speech API の対応が不完全な場合があります。
  • HTTPS または localhost 以外では動作しません。
Q すぐに認識が止まってしまう
A
  • 「自動で再開する」チェックを有効にしてください（トグルモードのみ）。
  • 無音が続くと認識エンジンが自動的に停止することがあります。これはブラウザの仕様です。
Q 認識精度が低い / 違う言葉として認識される
A
  • マイクを口に近づけ、はっきり発話してください。
  • エモート辞書に登録することで、誤認識される語句を正しいコードに変換できます。
  • 送信・キャンセルコマンドを認識されやすいワードに変更してみてください。
📤 チャット送信
Q 送信コマンドを言っても送信されない
A
  • 「詳細設定」の送信コマンド欄に入力した語句と一致しているか確認してください。
  • 「認識中...」エリアに表示されたテキストがコマンドと一致するか確認してみてください。
Q 送信エラーが出る / チャットに反映されない
A
  • アクセストークンが失効している可能性があります。一度 Logout してログインし直してください。
  • 送信先チャンネルの入力が正しいか確認してください（空欄 = 自分のチャンネル）。
  • ブラウザの Developer Tools (F12) → コンソールで詳細なエラーを確認できます。
⚙️ 設定・認証
Q Client ID を再設定したい
A
ログイン画面の 「Client ID を再設定」 ボタンをクリックしてください。またはブラウザの localStorage をクリアしてページをリロードすることでも初期化できます。
Q 辞書データが消えた
A
辞書はブラウザの localStorage に保存されています。ブラウザのキャッシュ・サイトデータを削除すると失われます。定期的に ⬆ Export でバックアップしておくことを推奨します。
📋 ログを取得して報告する

  1. 「詳細設定」→「デバッグログを表示する」をオン

  2. 問題が起きる操作を再現する

  3. ログ欄の 📋 ログをコピー をクリック

  4. コピーした内容を開発者に共有する
